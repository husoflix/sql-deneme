	1- create database
sqlde yeni bir veritabanı oluşturmak için kullanılan create databse ifadesi açıkça anlatılmış temel syntaxı şu şekilde ;

create database databasename;

yani diyorsun ki create database testDB; komutunu girersen adında bir veri tabanı oluşturur ama bu işlemi yapabilmen için admin yetkisine sahip olman lazım oluşturduktan sonra veritabanını doğrulamak için ;

Show databases;
komutunu kullabilirsin bu komut sistemdeki tüm dbleri görmeni sağlar

	2-drop database
mevcut databaseyi tamamen silmek için kullanılır yani drop demek sistemden tamamen kaldırmak demek 

örnek syntax

	5- drop table
bir tablonun tamamıyla sistemden siliyorsak işte bu komutla yapıyoruz silme işlemi ile birlikte tablo yapısı verileri sütunlar her şeyi uçup gidiyor

drop table shippers;
bu komut ilgili tabloyu ve içindeki tüm verileri siler 


truncate table ile arasındaki fark 

truncate table tablodaki verileri siler ama yapı sütun index constraint falan yerinde kalır

drop  table ise tabloyu bütünüyle kaldırır 

if exist ile daha güvenli kullanım (hata önleme)

drop table if exist tablo_adi;

	8-auto increment
otomatik artan bir sütun her yeni kayıt eklendiğinde otomatik olarak benzersiz bir sayı üretiyor genellikle bir tablonun primary key sütununda bu kullanılıyor
böylece sen id değerini elle girmezsen bu sistem senin için sırayla sayar hem pratik hem hata riskini azaltır 

 ek özellikler 
başlangıç değeri (start) ve artış miktarı(increment) gebelde tanımlanabilir örneğin sql server da identity(10,5) yaparsan yeni kayıtlar 10 dan başlar sonra 15 20 25 30 şeklinde gider 

mysqlde başlangıç değerini değiştirmek için;
 
alter table persons auto_increment = 100;

	10-view
sqlde sanal tablo (virtual table) demek yani fiziksel olarak veriler ayrı bi yerde saklanmaz senin yazdığın select sorgusunun sonucu her sorgulandığında dinamik oluşur 
bir view gerçek tablolardaki sütunlardan gelir (bir veya daha fazla tabloyu kullanabilir) view kullanıca sanki tek bir tabloymuş gibi veri sunar 
view her sorgulandığında güncel veri gösterir yani underlying(temel) tablolar değiştiyse viewın sonucu da değişir

create view [brazil customers] as
select customername, conctactname
from customers
where country = 'brazil';
 Brezilyalı müşterileri sıralamaya yarar

yukarıdaki görünümü aşağıdaki gibi sorgulayabiliriz 
 
select * from [brazil customers];

sql updating a view (create or replace view)

create or replace view view_adi as.. kullnarak var olan view ı güncelleytebilrisiniz böylece yeni sütun eklemek , koşulu değiştirmek gibi işlemler için sil yeni oluıştur gibi uğraşma gerekmez

güvenlik bazı sütunları ya da satırları gizleyebilirsin kullanıcı sadece izin verilen sütunları ya da satırları view aracılığıyla  


	11- injection 
kullanıcı girişinden gelen verinin kötü niyetli, kod ekleyerek(injection) sql sorgusuna dahil edilmesiyle oluşan saldırı tekniğidir bu saldırı veritabanına zarar verebilir hassas verileri açığa çıkarabilir ya da kontrolü ele geçirmeye sebep olabilie 

bazı örnekler :


kullanıcıdan userid isteyip bunu direkt sql sorgusuna eklemek 

select * from users where userid = <kullanıcıdan gelen veri>;




eğer kullanıcı 105 or 1=1

select * from users where userid = 105 or 1=1

bu sorgu her zaman doğru olur tüm kullanıcıları çeker 

kullanıcı adı ve şifre alanı var :

select * from users where name = " kullanıcıadı" and pass = "şifre";
bu adı alanına " or " "=" gibi bir şeey ayzarsa sorgunun mantığı bozulur filtere etkinsizleşir ve yetkisiz erişim sağlanabilir 
ya da saldırı şöyle olabilir kullanıcı girişine ; deop table suppliers gibi bir şey girerek tablo silme işlemi tetiklemek

$user = $_POST['username'];
